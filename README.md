# Point Cloud Classification: PointNet vs. MLP

A PyTorch project exploring how permutation invariance affects 3D object classification. It compares a PointNet classification model with an MLP of approximately equal parameter count, then investigates how random permutations of the input points affect both models.

The experiments use a preprocessed ShapeNet subset containing cars, planes, and sofas. This dataset came as part of a university course project and the project itself was in part assisted by the course material, although much of the content is completely original.

## Contents

- PointNet classification with input and feature T-Nets, shared pointwise layers, max pooling and feature transform orthogonality regularization.
- An MLP baseline with shared pointwise layers and an order-dependent final classifier, designed to closely match PointNet's parameter count.
- Deterministic point subsampling and separate training, validation and test sets.
- Training histories stored in model checkpoints, learning curves, test metrics, confusion matrices, and interactive point cloud visualizations.
- Evaluation on shuffled point clouds and a further MLP training run with new point permutations during training.

## Tools

Python, Jupyter Notebook, PyTorch, NumPy, scikit-learn, Trimesh, pandas, Matplotlib, Plotly and tqdm.

The notebooks include saved outputs and can be viewed directly on GitHub or opened in Jupyter.

## Running locally

Use Python 3.14 and install the required packages:

```bash
python -m pip install torch numpy scikit-learn trimesh pandas matplotlib plotly tqdm"
```

From the repository folder, open the notebook:

```bash
jupyter notebook pointnet_vs_mlp.ipynb
```
